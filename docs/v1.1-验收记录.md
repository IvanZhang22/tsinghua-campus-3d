# v1.1 首批校准版验收

日期：2026-10-04。环境：Windows、Codex 内置浏览器、生产构建。浏览器缩放后实际 DOM 桌面尺寸 1200×750，手机尺寸 325×703；设置尺寸分别为 1440×900、390×844。

## 已检查

- 类型检查、12 项 Node 测试及 Vite 生产构建通过。测试覆盖稳定地点 ID、风物和教学楼登记、楼群轮廓、坐标转换、确定性布景、池塘和道路避让、分享链接迁移与参数边界。
- 简称“一教”“六教”“法图”可找到对应地点；移除介绍文字导致的“六教”误匹配四教。能动系及热能系增加常用名称。
- 选择建筑后飞至近景。六教三个轮廓、图书馆三个轮廓、主楼六个体量分开组织。
- 植被滑块从 0 到 150 即时更新，冬季颜色与花量响应；种子更换保留地理布局。
- 实拍照片可放大。弹窗移至页面顶层，避免被浮动面板裁切；署名与授权链接可见。
- 分享后重新打开链接，恢复机械工程馆与画面参数；旧版机位通过单元测试迁移到新布局。
- 导览暂停后可继续、跳到下一站及退出；截图明信片生成 PNG 并保存。截图见 screenshots/v1.1。
- 手机抽屉、搜索、照片放大正常；DOM 无横向溢出。二维模式使用同一建筑轮廓、道路、水系与稳定地点 ID。
- 本地桌面生产画面记录约 77 帧/秒、341 绘制批次。这是当前电脑和当前场景的采样，不是所有设备的承诺；手机尺寸模拟不等于实机手机性能验收。

## 当前资料和验收限制

- 地形尚为平面：未完成 3–5 米局部起伏、六教下沉广场、池岸、桥面与建筑基底的真实高程衔接。
- 2014 年轮廓、官方示意图注册与 POI 坐标的全校误差尚未量化，不能将两个控制点的误差外推至全校。
- 首批有授权照片的地点为 30 处，其余地点明确显示待补充。多角度精细模型、门饰、真实看台设施、分区加载与更多远近细节仍需迭代。
- 历史动画按本轮范围暂缓。当前应用展示当代校园；旧版静态历史控件已退出主界面。
- 开发热更新出现过 Drei/React 根卸载警告；需以生产页面日志为准。发布后另行记录公开站点检查结果。
- Vercel 预览构建和 GitHub 检查成功。内置浏览器访问预览触发 Vercel 登录跳转，平台登录页面因连接关闭无法打开；没有关闭预览保护，正式公开域名继续单独验收。
